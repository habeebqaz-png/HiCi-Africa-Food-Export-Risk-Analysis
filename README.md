# HiCi Ltd – Africa Food Export Risk Analysis

## Project Overview
This project analyses EU food-safety notifications to identify risks affecting African food exports, using HiCi Ltd as a case study. The analysis examines notification patterns, border rejections, affected product categories and countries of origin.

## Project Objectives
- Examine EU food-safety notifications and border rejection patterns.
- Identify product categories with frequent rejection notifications.
- Investigate the countries associated with rejected food products.
- Assess risks affecting African food exports.
- Develop recommendations to reduce export rejection and improve compliance.

## Dataset Overview
- Total EU food-safety notifications: 513
- Border rejections: 339
- Analysis period: 1999–2019

## Tools Used
- Microsoft Excel
- Excel formulas and functions
- PivotTables
- COUNTIFS
- Data analysis and reporting

## Key Findings
- Greece recorded 223 notifications in the analysed data.
- Nuts, nut products and seeds accounted for 318 notifications.
- Sudan was the origin of 180 rejected nuts.
- Re-dispatch was recorded in 121 cases.

## Recommendations
- Strengthen supplier quality control and product testing.
- Improve traceability and export documentation.
- Prioritise compliance checks for high-risk product categories.
- Ensure food products meet relevant EU food-safety requirements.

## Conclusion
The analysis highlights important food-export risks and demonstrates how data analysis can support better export decisions, risk management and regulatory compliance.
